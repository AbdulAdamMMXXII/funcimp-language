# funcimp language
FuncIMP is a small programming language developed for the Programming Language Principles, Design, and Implementation (PLPD&I) module at the University of Birmingham.

The language is based on IMP and extends it with:

Functions
Local definitions
Print operations
This repository contains:

Language specification
Interpreter implementation
Parser
Example programs
Project report
Status
Project setup and initial design phase.
